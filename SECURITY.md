# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.2.x   | :white_check_mark: |
| < 1.2.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within **nexus-serena-mcp**, please report it responsibly by opening a security advisory or contacting NexusVibe AI Tech via GitHub Issues.

We appreciate your effort to responsibly disclose findings and will respond promptly to assess and address valid vulnerabilities.
